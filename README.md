# Otto Odontologia — landing page conceitual

Landing page de uma clínica odontológica **fictícia**, desenvolvida como projeto de portfólio.

> ⚠️ **Aviso:** a clínica Otto Odontologia, sua equipe, endereço, números, avaliações e depoimentos são **fictícios** e servem apenas para demonstração. Nenhuma informação deste projeto representa pacientes, profissionais ou estabelecimentos reais. As informações sobre tratamentos são gerais e não substituem a avaliação de um cirurgião-dentista.

## Sobre o projeto

- **Objetivo:** apresentar uma clínica de odontologia contemporânea, com foco em prevenção e atendimento sem pressa, e conduzir o visitante a solicitar uma avaliação.
- **Conversão:** botão de WhatsApp demonstrativo e formulário que **não envia nem armazena dados**.
- **Identidade visual:** fundo marfim, azul-petróleo e coral suave; tipografia Fraunces e Source Sans 3.

## Tecnologias

- [Next.js](https://nextjs.org) (App Router) com TypeScript
- CSS Modules
- ESLint
